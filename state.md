# Система начисления баллов за задания ЕГЭ по русскому языку

## Общие правила

В варианте ЕГЭ по русскому языку есть **26 заданий**.

Для каждого задания заранее задано максимальное количество первичных баллов.

### Правило начисления

- Если задание выполнено полностью правильно — начисляется **максимальный балл**, указанный для этого задания.
- Если задание выполнено неправильно — начисляется **0 баллов**.
- Для заданий, где максимальный балл равен `2`, необходимо корректно выполнить все требования задания, чтобы получить 2 балла.
- Для заданий 8 и 22, выставляется 1 балл соответственно если допущена ошибка на 1 или 2 позициях из 5. Если на более чем 2 допущена ошибка -- выставляется 0 баллов
- Для заданий с максимальным баллом `1` за полностью правильное выполнение начисляется 1 балл.


**Максимальное количество первичных баллов за весь вариант: 28.**
