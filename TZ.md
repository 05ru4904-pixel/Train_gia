Техническое задание — Telegram-бот для подготовки к ЕГЭ
=======================================================

1\. Общая информация
--------------------

Разработать Telegram-бота для подготовки школьников к ЕГЭ.

Основная часть продукта — **Telegram Mini App**, в котором пользователь выполняет задания и отслеживает свой прогресс.

На первом этапе реализуется только **ЕГЭ по русскому языку**. В дальнейшем планируется возможность добавления других предметов.

**Цель:** удобная тренировка заданий ЕГЭ, работа над ошибками и отслеживание прогресса.

2\. Структура Mini App
======================

В нижней части Mini App расположены 3 раздела:

1.  **Тренажёр**
    
2.  **Статистика**
    
3.  **Профиль**
    

3\. Раздел «Тренажёр»
=====================

Два режима:

### 3.1. Тренировать конкретное задание

Пользователь выбирает задание **№1–26**.

Возле каждого номера отображается краткая тема задания.

После выбора пользователь выбирает количество вопросов:

*   6
    
*   9
    
*   12
    
*   15
    

После этого запускается тренировка.

### 3.2. Полный вариант ЕГЭ

Пользователь может выбрать полный вариант, состоящий из заданий **№1–26**.

Задание №27 на первом этапе не реализуется.

Полный вариант проходит с ограничением по времени. Регламент, время и система начисления баллов должны соответствовать актуальному регламенту ЕГЭ.

4\. Обычная тренировка
======================

После выбора задания и количества вопросов система случайным образом выбирает необходимое количество **уникальных заданий** из базы.

Например:

**№4 → 12 вопросов**

Система выбирает 12 разных заданий №4.

В рамках одной тренировки задания не повторяются.

Если в базе недостаточно заданий для выбранного количества, пользователь получает соответствующее уведомление.

### Проверка ответа

После выбора ответа сразу показывается результат:

**Правильно:**

> ✅ Верно!

**Неправильно:**

> ❌ Неверно
> 
> Правильный ответ: А

После этого появляется кнопка **«Следующее задание»**.

Повторно решить задание или изменить уже данный ответ нельзя.

5\. Варианты ответов
====================

Количество вариантов ответа не ограничивается четырьмя.

Система должна поддерживать:

*   4 варианта;
    
*   5 вариантов;
    
*   6 вариантов;
    
*   и больше.
    

Также должна поддерживаться возможность **нескольких правильных ответов**.

Например:

6\. Результат тренировки
========================

После завершения тренировки пользователь получает:

*   количество заданий;
    
*   количество правильных;
    
*   количество неправильных;
    
*   процент правильных ответов;
    
*   список ошибок.
    

Пример:

> 🎉 Тренировка завершена
> 
> Заданий: 12
> 
> Правильных: 9
> 
> Неправильных: 3
> 
> Результат: 75%

Также пользователь может открыть свои ошибки и посмотреть задание и правильный ответ.

Кнопки:

*   **Повторить тренировку**
    
*   **Вернуться в тренажёр**
    

7\. Незавершённая обычная тренировка
====================================

Ограничения по времени нет.

Если пользователь вышел из Mini App:

*   прогресс сохраняется;
    
*   уже данные ответы сохраняются;
    
*   пользователь может продолжить с того же места.
    

Одновременно может существовать только **одна незавершённая тренировка**.

Если пользователь начинает новую тренировку, предыдущая незавершённая тренировка автоматически сбрасывается.

В разделе «Тренажёр» отображается:

> **Продолжить тренировку**
> 
> №4 · 7/12 выполнено
> 
> **\[Продолжить\]**

8\. Полный вариант ЕГЭ
======================

Полный вариант состоит из заданий **№1–26**.

Пользователь может:

*   начать с любого задания;
    
*   переходить на любое задание;
    
*   пропускать задания;
    
*   возвращаться к пропущенным;
    
*   изменять ранее выбранный ответ;
    
*   завершить вариант досрочно.
    

### Навигация

Должна присутствовать панель навигации:

**1 2 3 4 5 6 ... 26**

Статус заданий отображается визуально:

*   🟢 отвечено;
    
*   ⚪ не отвечено.
    

9\. Таймер полного варианта
===========================

При начале полного варианта запускается таймер.

Если пользователь закрывает Mini App:

*   прогресс сохраняется;
    
*   ответы сохраняются;
    
*   таймер **не останавливается**.
    

При возвращении пользователь продолжает с того же места.

При достижении лимита времени вариант автоматически завершается.

### Пауза

Пользователь может остановить таймер.

Перед остановкой показывается предупреждение:

> ⚠️ **Остановить время?**
> 
> Рекомендуем останавливать время только если вам действительно пришлось внезапно отлучиться, а не с целью увеличить время на решение, так как это может повлиять на вашу подготовку.
> 
> Вы действительно хотите остановить время?
> 
> **\[Да\] \[Нет\]**

Если пользователь нажимает «Да», таймер останавливается.

Информация о паузе отдельно в статистике **не отображается**.

10\. Результат полного варианта
===============================

После завершения пользователь получает:

*   количество правильных ответов;
    
*   количество неправильных;
    
*   первичный балл;
    
*   тестовый балл;
    
*   затраченное время.
    

Расчёт баллов должен соответствовать актуальному регламенту ЕГЭ.

Результат сохраняется в истории пользователя.

11\. История полных вариантов
=============================

Пользователь может просматривать ранее пройденные полные варианты.

Для каждого результата сохраняются:

*   номер/ID варианта;
    
*   дата прохождения;
    
*   затраченное время;
    
*   количество правильных;
    
*   количество неправильных;
    
*   первичный балл;
    
*   тестовый балл.
    

12\. Раздел «Статистика»
========================

Статистика **накапливается** после каждой завершённой тренировки и полного варианта.

### Общая статистика

Отображается:

*   всего решено;
    
*   всего правильных;
    
*   всего неправильных;
    
*   процент правильных;
    
*   процент неправильных.
    

### Статистика по заданиям

Для каждого задания №1–26:

> **№4 — Орфоэпические нормы**
> 
> Решено: 120
> 
> Правильно: 96
> 
> Неправильно: 24
> 
> Точность: 80%

### Фильтр по дате

Пользователь может выбрать период:

> С 01.09.2026
> 
> По 30.09.2026

Статистика пересчитывается только за выбранный период.

Фильтр должен работать:

*   для общей статистики;
    
*   для статистики по каждому заданию;
    
*   для результатов полных вариантов.
    

13\. Раздел «Профиль»
=====================

В профиле отображается:

*   имя пользователя;
    
*   Telegram username;
    
*   текущий тариф: Free / PRO;
    
*   дата окончания подписки;
    
*   дата регистрации.
    

Кнопки:

*   **Управление подпиской**
    
*   **Тарифы**
    

Функционал подписки будет подробно определён позже.

14\. Авторизация
================

Отдельная регистрация не требуется.

При первом запуске Mini App:

*   пользователь автоматически создаётся;
    
*   для идентификации используется Telegram ID;
    
*   имя и username берутся из Telegram;
    
*   при последующих запусках пользователь автоматически авторизуется.
    

15\. База заданий
=================

Все задания хранятся в базе данных.

Каждому заданию автоматически присваивается **уникальный ID**.

ID используется для:

*   поиска;
    
*   редактирования;
    
*   удаления;
    
*   добавления задания в полный вариант;
    
*   повторного использования задания;
    
*   ведения статистики.
    

16\. Админ-бот
==============

Для управления заданиями используется **отдельный Telegram-бот**.

Отдельная веб-админка на первом этапе не требуется.

Администратор добавляет задания через Telegram по установленному шаблону.

17\. Управление заданиями через админ-бот
=========================================

Админ-бот должен позволять:

*   добавлять задания;
    
*   редактировать задания;
    
*   удалять задания;
    
*   находить задания по ID;
    
*   просматривать задания;
    
*   добавлять новые задания в базу.
    

18\. Добавление полного варианта
================================

Должна быть возможность добавить целый вариант ЕГЭ, состоящий из заданий №1–26.

При добавлении целого варианта:

*   каждое задание сохраняется отдельно;
    
*   каждому заданию автоматически присваивается уникальный ID;
    
*   задания становятся частью общей базы.

20\. Дизайн Mini App
====================

Стиль:

*   современный;
    
*   минималистичный;
    
*   светлая цветовая гамма;
    
*   преимущественно белый фон;
    
*   нейтральные оттенки;
    
*   без чрезмерно ярких и светящихся элементов;
    
*   минимум визуального шума;
    
*   удобство длительного использования;
    
*   адаптация под мобильные экраны Telegram Mini App.
    

Основные шрифты:

*   **Manrope**
    
*   **SF Pro Text**
    

21\. Что не реализуется на первом этапе
=======================================

На первом этапе не реализуются:

*   задание №27;
    
*   теория;
    
*   учебные материалы;
    
*   сложная система геймификации;
    
*   отдельная веб-админка;
    
*   другие предметы ЕГЭ;
    
*   подробная система подписок и тарифов.
    

Эти функции могут быть добавлены на следующих этапах.
